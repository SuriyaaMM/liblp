# MXI4FP32
- Our custom implementation derived from [MXFP4](https://www.opencompute.org/documents/ocp-microscaling-formats-mx-v1-0-spec-final-pdf/)

## Specification
- Element
    - Element Data Type : INT4 (4 bit integer)
- Shared Scale 
    - 32 bits (IEEE Floating Point)
    - 32 scalar elements share the scale
